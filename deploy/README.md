# Как поднять бота на сервере, чтобы он работал всегда

Сейчас бот живёт только пока открыт твой компьютер и запущена консоль.
Чтобы он отвечал круглосуточно и не зависел от тебя — нужен сервер (VPS).

---

## Два жёстких условия при выборе сервера

Это не придирки, а то, на чём легко потерять деньги и вечер.

**1. Локация вне России.**

`api.telegram.org` в России блокируется на уровне TCP — проверено: пинг
проходит, а соединение не устанавливается. На российском IP бот запустится
без единой ошибки и будет молчать.

Бери локацию **Нидерланды, Германия, Финляндия, Польша или Казахстан**.

**2. Оплата российской картой.**

Многие зарубежные хостинги карты РФ не принимают. Ищи российские хостинги,
у которых есть зарубежные локации — тогда и оплата проходит, и IP не под
блокировками.

---

## Что брать

Бот почти ничего не ест. Самый минимальный тариф:

| Параметр | Сколько нужно |
| --- | --- |
| Ядра | 1 |
| Память | 1 ГБ (хватит с большим запасом) |
| Диск | 10 ГБ |
| ОС | Ubuntu 22.04 или 24.04 |

Ориентир по цене — **150–400 ₽ в месяц** за минимальный тариф.
Цены меняются, поэтому проверяй на сайте хостинга, а не верь на слово.

Это примерно 3–8% от одного заказа на 5000 ₽. То есть окупается первым
же клиентом.

## Установка: одна команда

Подключись к серверу:

```bash
ssh root@АДРЕС_СЕРВЕРА
```

Скачай и запусти скрипт установки:

```bash
curl -fsSL https://raw.githubusercontent.com/n1lokaDeep/findgig/main/deploy/setup.sh -o setup.sh
bash setup.sh
```

Скрипт спросит две вещи:

```
BOT_TOKEN: 8879014814:AAFW...
ADMIN_IDS: 6584827038
```

Токен — от `@BotFather`, свой ID — от `@userinfobot`.

Дальше он сам:

1. Поставит Python и git
2. Создаст отдельного пользователя `findgig` — бот не будет работать от root
3. Склонирует код в `/opt/findgig`
4. Соберёт виртуальное окружение и поставит зависимости
5. Создаст `.env` с правами `600`
6. **Прогонит самопроверку** — если переводы или база сломаны, установка
   остановится до запуска бота
7. Настроит службу systemd и запустит бота

В конце покажет состояние. Если увидишь `active (running)` — всё работает.

---

## Почему это «держится всегда»

Служба systemd с `Restart=always` и `RestartSec=5`:

- **сервер перезагрузился** → бот поднимется сам
- **бот упал с ошибкой** → поднимется через 5 секунд
- **бот съел всю память** → `MemoryMax=512M` убьёт процесс, systemd его вернёт

Вмешиваться руками не нужно. Один раз настроил — работает.

---

## Управление

```bash
journalctl -u findgig -f          # логи в реальном времени
systemctl status findgig          # состояние
systemctl restart findgig         # перезапустить
systemctl stop findgig            # остановить
```

Логи хранятся в journald и не растут бесконечно — старые удаляются сами.

## Обновить бота после правок

Когда поправишь код и запушишь в GitHub:

```bash
bash /opt/findgig/deploy/setup.sh
```

Скрипт сделан повторяемым: подтянет новый код, обновит зависимости,
перезапустит бота. **База и `.env` при этом не трогаются.**

Если правишь тексты прямо на сервере:

```bash
sudo -u findgig nano /opt/findgig/config.py
systemctl restart findgig
```

## Не забыть про базу

Вся база — один файл `/opt/findgig/bot.db`. В нём все люди, задачи и отклики.

**Раз в неделю делай копию**, иначе потеряешь всё при переустановке:

```bash
cp /opt/findgig/bot.db ~/bot-$(date +%F).db
```

Можно повесить в cron, чтобы не помнить об этом:

```bash
crontab -e
# добавить строку:
0 4 * * * cp /opt/findgig/bot.db /root/bot-$(date +\%F).db
```

## Про бесплатные варианты — честно

Бесплатного «работает всегда» не существует, и вот почему:

| Вариант | Почему не подходит |
| --- | --- |
| Бесплатные тарифы зарубежных хостингов | Засыпают без нагрузки, часто требуют зарубежную карту для проверки |
| Старый телефон с Termux | Android убивает процесс, нужен постоянный VPN — на день-два хватит, на месяц нет |
| Твой компьютер 24/7 | Бесплатно, но зависит от тебя: перезагрузка, отключение света, VPN |
| GitHub Actions по расписанию | Не подходит для бота: он должен отвечать сразу, а не раз в 5 минут |

**Свой компьютер с автозапуском** — единственный реально бесплатный вариант.
Он не «независим от компьютера», но если задача просто в том, чтобы бот
не умирал после перезагрузки Windows, этого достаточно. Скажи — настрою.

Если готов платить 200–300 ₽ в месяц — сервер лучше во всём: бот не зависит
от твоего компьютера, света и VPN.
